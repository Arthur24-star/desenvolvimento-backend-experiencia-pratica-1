# desenvolvimento-backend-experiencia-pratica-1# 📚 Experiência Prática I – Desenvolvimento Back-end

## 📖 Sobre o projeto

Este projeto foi desenvolvido como parte da disciplina de **Desenvolvimento Back-end** da faculdade.

O objetivo foi compreender, na prática, como ocorre a comunicação entre o **Front-end** e o **Back-end** em uma aplicação web real, utilizando as ferramentas de desenvolvedor (DevTools) do navegador.

Para a análise, foi utilizada a plataforma **YouTube**.

---

## 🎯 Objetivos

- Compreender a arquitetura Cliente-Servidor.
- Analisar requisições HTTP.
- Identificar métodos HTTP e códigos de status.
- Interpretar respostas em formato JSON.
- Documentar o fluxo de comunicação entre cliente e servidor.

---

## 🛠️ Ferramentas utilizadas

- Google Chrome DevTools
- Aba Network
- Draw.io / Canva (Fluxograma)
- GitHub

---

## 🔍 Etapas realizadas

- Escolha da aplicação web (YouTube)
- Mapeamento da arquitetura Cliente-Servidor
- Captura de requisições HTTP
- Identificação de Endpoints
- Análise de métodos HTTP
- Identificação dos Status Codes
- Interpretação de respostas JSON
- Elaboração de Fluxograma
- Desenvolvimento de Relatório Técnico
